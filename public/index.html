다운로드

왜

그물무늬는 노이즈가 아니에요

AI는 작은 밑그림을 그린 뒤 "확대 기계"로 2배씩 여러 번 키워요. 이 기계가 빈 칸을 채울 때 한 칸은 진하게, 한 칸은 연하게 채우는 버릇이 있어서, 페인트 롤러 자국처럼 같은 크기·같은 방향의 무늬가 화면 전체에 깔립니다. 하늘이나 흰 옷에선 묻히지만, 어둡고 자잘한 숲 바닥에선 잘 보여요. 규칙이 있는 무늬라서 일반 노이즈 제거기는 "원래 그림"으로 보고 그냥 둡니다.

어떻게

"어디를"이 아니라 "어떤 무늬를" 지워요

합창단에서 한 사람이 계속 "삐—" 소리를 내면, 전체 볼륨을 줄이는 대신 그 음 하나만 빼면 되죠. 영상을 128×128 조각으로 나눠 주파수 지도로 바꾼 뒤, 45° 대각선·2~3픽셀 간격에 해당하는 네 모서리 영역만 줄이고 다시 합쳐요. 밝기(Y) 채널만 다루고 색(UV)과 오디오는 원본 그대로 두기 때문에, 대부분의 픽셀은 255단계 중 1~2단계만 바뀝니다.

보안

영상은 이 탭 밖으로 나가지 않아요

디코딩·보정·인코딩 모두 브라우저 안의 WebAssembly(ffmpeg)와 Web Worker에서 돌아가요. 페이지에는 외부 서버로의 전송을 막는 보안 정책(CSP: connect-src 'self')이 걸려 있고, 엔진 파일까지 모두 같은 도메인에서 받아요. 작업이 끝나면 탭을 닫는 순간 메모리에서 사라집니다.
