그물무늬만 골라서 지워요

AI가 영상을 키울 때 남기는 그물무늬(롤러 자국)만 지우고, 다시 압축할 때 생기는 손실 없이 저장해요. 흐리게 뭉개지 않아서 나뭇잎과 지푸라기는 그대로 남아요.

사용 방법

  1. 1
    영상 넣기

    파일은 이 브라우저 탭 안에서만 열려요.

  2. 2
    무늬 확인

    비교 보기와 5배 돋보기로 보정 전후를 확인해요.

  3. 3
    무손실 저장

    다시 압축 손실 없이 합치고, 오디오는 원본 그대로 넣어요.

로컬 전용 · 업로드 없음

  • 영상은 서버로 업로드되지 않아요. 디코딩·보정·인코딩 모두 브라우저 안의 WebAssembly(ffmpeg)와 Web Worker에서 돌아가요.
  • 외부 전송을 막는 보안 정책(CSP: connect-src 'self')이 걸려 있어서, 영상 데이터를 다른 서버로 보낼 수 없어요.
  • 처리 엔진과 서체까지 모두 같은 도메인에서 받아요. 외부 CDN 요청이 없어요.
  • 작업 결과는 이 탭의 메모리에만 있고, 탭을 닫으면 사라져요.

그물무늬는 노이즈가 아니에요

AI는 작은 밑그림을 그린 뒤 "확대 기계"로 2배씩 여러 번 키워요. 이 기계가 빈 칸을 채울 때 한 칸은 진하게, 한 칸은 연하게 채우는 버릇이 있어서, 페인트 롤러 자국처럼 같은 크기·같은 방향의 무늬가 화면 전체에 깔려요. 하늘이나 흰 옷에선 묻히지만 어둡고 자잘한 숲 바닥에선 잘 보여요.

"어디를"이 아니라 "어떤 무늬를" 지워요

영상을 128×128 조각으로 나눠 주파수 지도로 바꾼 뒤, 45° 대각선·2~3픽셀 간격에 해당하는 영역만 줄이고 다시 합쳐요. 밝기(Y) 채널만 다루고 색(UV)과 오디오는 원본 그대로 둬서, 대부분의 픽셀은 255단계 중 1~2단계만 바뀌어요.
